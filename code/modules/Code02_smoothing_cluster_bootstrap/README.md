# Code 2 — smoothing, background and record-cluster bootstrap

Run `Rscript run.R` for 5,000 bootstrap resamples. Required analysis package: `npreg`. Outputs are written under `outputs/`.

Complete record-bin trajectories are sampled with replacement. The observed trajectory is fitted with `npreg::ss`; bootstrap percentile bounds are 2.5% and 97.5% (R quantile type 7). The prediction grid has 481 points. Seed 20260820 is reset for each panel; R RNG settings are Mersenne-Twister/Inversion/Rejection.

Global 50-kyr smoothing uses `spar=0.2`. Temporal-resolution panels use `spar=0.2` for 50 and 100 kyr and `spar=0.3` for 150 and 200 kyr. Positive record-bin IQRs are used for Global EV and Fig. S3. The background is the equal-window mean `0.34503257945945265`.

Proxy panels use their supplied workbook-derived record and bin-mean tables, including the zero-IQR rows present in those inputs. These inputs are separate from the Global EV long table.

Run `Rscript run_proxy_correlations.R --current-inputs` for 12 two-sided Pearson EV–proxy tests: four proxies across the full interval, Phase 1 (66.45–66.90 Ma) and Phase 2 (66.05–66.40 Ma). Missing bins are omitted without interpolation; P values are nominal. The plot reads the supplied current summaries in `reference_results/current_dataset/`.

Plot commands:

- `Rscript plots/plot_Fig2A_background_comparison_Arial_20261009.R`
- `Rscript plots/plot_FigS3_final_from_locked_inputs.R`
- `Rscript plots/plot_ancillary_FigS10_from_locked_inputs.R`
- `Rscript plots/plot_EV_proxy_correlations_final.R`

Plot scripts read the supplied fit, interval or correlation summaries and write under `outputs/plots/`. Plotting requires the packages listed in those scripts, including readr, dplyr, svglite and ragg. The Fig. 2A script requires macOS Quartz and Arial. Complete Fig. 2 event artwork is not generated by this module.
